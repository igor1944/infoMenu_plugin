# InfoMenu

Плагин для **Paper 1.18.2**, который показывает здоровье игрока (или моба), на которого вы
смотрите, и сколько урона вы ему нанесли. Все настройки вынесены в `config.yml` и дублируются
в игровом меню — менять их можно прямо на сервере.

## Что умеет

- **Здоровье цели под прицелом.** Плагин периодически определяет, на кого смотрит игрок,
  и выводит имя цели, текущее и максимальное здоровье, процент и полоску из сердец.
- **Два способа вывода:** строка над хотбаром (`ACTION_BAR`) или полоса босса (`BOSS_BAR`),
  цвет которой зависит от количества здоровья.
- **Нанесённый урон.** Считается урон, который вы нанесли конкретной цели — в ближнем бою,
  из лука, трезубцем и даже от вашего прирученного животного. Счётчик хранится ограниченное
  время (по умолчанию 10 секунд), поэтому показывает актуальный урон, а не сумму за всю сессию.
- **Личные настройки для каждого игрока.** Каждый игрок настраивает показ под себя;
  настройки сохраняются в `plugins/InfoMenu/users.yml` и переживают перезапуск сервера.
- **Меню настроек** по команде `/infomenu` — всё переключается кликами, без правки конфигов.

## Установка

1. Соберите плагин: `mvn clean package`
2. Положите `target/infomenu-1.0.0.jar` в папку `plugins/` вашего сервера.
3. Перезапустите сервер — рядом с jar-файлом появится `config.yml`.

## Команды

| Команда | Описание | Право |
| --- | --- | --- |
| `/infomenu` | Открыть меню настроек | `infomenu.use` |
| `/infomenu toggle` | Быстро включить/выключить показ здоровья | `infomenu.use` |
| `/infomenu health <игрок>` | Показать здоровье игрока | `infomenu.use` |
| `/infomenu reset` | Сбросить свои настройки к значениям из конфига | `infomenu.use` |
| `/infomenu reload` | Перезагрузить `config.yml` | `infomenu.admin` |

Псевдонимы: `/im`, `/healthmenu`.

- `infomenu.use` — выдаётся всем по умолчанию;
- `infomenu.admin` — по умолчанию у операторов.

## Меню настроек

| Слот | Что меняет |
| --- | --- |
| Краситель | Показать/скрыть здоровье цели |
| Часы | Способ вывода: Action Bar → Boss Bar → Выключено |
| Красная краска | Полоска из сердец |
| Меч | Показ нанесённого урона |
| Око эндера | Дальность (8 → 16 → 32 → 48 → 64 блоков) |
| Голова зомби | Только игроки или все существа |
| Звезда Незера | Сбросить свои настройки |

## config.yml

Основные параметры:

```yaml
enabled: true              # полный переключатель плагина

display:
  mode: ACTION_BAR         # ACTION_BAR | BOSS_BAR | NONE
  refresh-interval: 10     # обновление в тиках (20 тиков = 1 секунда)
  max-distance: 32         # дальность в блоках
  players-only: true       # true — только игроки, false — и мобы
  format: '&f%target% &8| %hearts% %color%%health%&c❤&7/&f%max_health% &8(%percent%%)%damage_line%'

damage:
  enabled: true            # считать нанесённый урон
  memory-seconds: 10       # сколько секунд помнить урон по цели
```

### Плейсхолдеры в `format`

| Плейсхолдер | Значение |
| --- | --- |
| `%target%`, `%name%` | Ник игрока или название существа |
| `%entity%` | Тип существа (Player, Zombie, …) |
| `%health%` | Текущее здоровье |
| `%max_health%` | Максимальное здоровье |
| `%percent%` | Процент здоровья (0–100) |
| `%color%` | Цвет по проценту здоровья (`&a` / `&e` / `&c`) |
| `%hearts%` | Полоска из сердец |
| `%damage%` | Нанесённый цели урон |
| `%damage_line%` | Готовый блок с уроном (пусто, если урона не было) |

Полный список настроек с пояснениями — в [`config.yml`](InfoMenu/src/main/resources/config.yml).

## Структура проекта

```
com.infoMenu
├── InfoMenu                 — точка входа, сборка компонентов
├── command/InfoMenuCommand  — /infomenu и автодополнение
├── config/PluginSettings    — чтение config.yml
├── display
│   ├── DamageTracker        — учёт нанесённого урона
│   ├── DisplayMode          — ACTION_BAR / BOSS_BAR / NONE
│   ├── HealthDisplayTask    — поиск цели и вывод информации
│   └── HealthFormatter      — сборка строки и полоски сердец
├── menu
│   ├── InfoMenuListener     — клики в меню
│   ├── MenuItems            — сборка предметов
│   └── SettingsMenu         — само меню настроек
├── user
│   ├── UserSettings         — личные настройки игрока
│   └── UserStore            — хранение в users.yml
└── util/Text                — цветовые коды и форматирование чисел
```
